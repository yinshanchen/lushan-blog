# 鹿山博客

一个可以自己拥有的写作站程序 —— 下载、双击、开站。

![版本](https://img.shields.io/badge/版本-v2.9.0-blue)

---

## 这是什么

鹿山博客是一个**写作站程序**：它把"你的网站"变成一个可以放在自己电脑上的东西。

你写文章、记随笔、存照片，它就是你的站点；你打开浏览器，它就是你的博客。

- **完全属于你**：文章、图片、留言都存在你自己的电脑里，不在任何公司的服务器上。
- **不需要配置**：下载解压，双击一个文件就跑起来，运行环境已经打包在内。
- **可以给朋友看**：你的站能生成一个地址，分享给别人访问（需自行部署到有公网地址的机器）。

## 下载安装

到本仓库的 **[Releases](https://github.com/yinshanchen/lushan-blog/releases)** 页面下载对应你系统的安装包：

| 你的系统 | 下载哪个 |
|---|---|
| Windows | `hongchen-install-v*-win-x64.zip` |
| Mac（Apple 芯片 M1/M2/M3…） | `hongchen-install-v*-mac-arm64.tar.gz` |
| Mac（Intel 芯片） | `hongchen-install-v*-mac-x64.tar.gz` |

### 安装步骤

**Windows**
1. 下载 `.zip`，**右键 → 全部解压缩**（不要直接在压缩包里双击运行）
2. 进入解压出来的文件夹，双击 **`startup.bat`**
3. 浏览器会自动打开你的站（地址 `http://localhost:1415`）

**Mac**
1. 下载 `.tar.gz`，双击解压
2. 进入解压出来的文件夹，双击 **`startup.sh`**
3. 如果提示「无法打开，因为来自身份不明的开发者」：**右键点 → 打开 → 再点「打开」**（只需做一次）
4. 浏览器会自动打开你的站

> 第一次启动要等几秒到半分钟（程序在初始化），之后启动很快。

## 功能概览

- **写作**：文章、随笔、每日照片，支持分类与关键字
- **阅读**：目录、搜索、按日期浏览
- **与人往来**：留言板、评论、私信（可与其它鹿山博客站点互通（云服务支持））
- **网站广场**：发现别人的站，收藏、互相串门
- **个人化**：背景图（可从官方图库选）、头像、自述、关键字、网站收藏
- **素材**：一键导出整站文章（备份 / 出书）、从别的平台导入文章
- **掌控**：留言、评论、私信可删可拉黑；不想被打扰时可开「闭关模式」

## 常见问题

**问：要花钱吗？**
答：程序本身免费。它跑在你自己的电脑上，要外网访问进网站广场，需要买云服务器。

**问：装了会不会弄乱我的电脑？**
答：不会。它就是一个文件夹，运行环境放在文件夹里的 `runtime/` 目录，不往系统里装东西。不想要了，删掉文件夹即可。

**问：我的文章在哪？**
答：就在程序文件夹里的 `app/data/` 目录，是你的东西，随时可以备份、拷走。

**问：能让别人访问我的站吗？**
答：可以，但需要一个别人能访问到的地址。在家用电脑上跑，只有你自己能看；要公开访问，需要部署到有公网 IP 或域名的机器上（可以一键搬迁）。

**问：Windows 提示"这个应用程序可能要依靠这个文件夹中其他压缩文件才能运行"？**
答：这是 Windows 在提醒你**不要直接在压缩包里运行程序**。先「全部解压缩」，再进文件夹双击 `startup.bat` 就好了。
